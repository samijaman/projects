## Projects

### NBA Team Rankings Using Massey Ratings
**Python | NumPy | Pandas | Linear Algebra**

Applied the Massey ranking method to NBA regular-season game data to estimate relative team strength using matrix-based modeling and point differentials.

Built a chronological train-test evaluation framework for predicting game outcomes and explored the effect of limiting large scoring margins on model performance.

**[View Project](./nba-massey-rankings/)**

---

### AI-Generated Text Detection Across LLMs
**Python | PyTorch | Hugging Face Transformers | DistilBERT | scikit-learn | NLP**

Compared Logistic Regression with Bag-of-Words and TF-IDF representations against a fine-tuned DistilBERT model for distinguishing AI-generated text from human-written text.

Evaluated classification performance, calibration, linguistic features, and generalization to text produced by previously unseen large language models.

**[View Project](./ai-text-detection/)**

---

### Patch-Based Detection of AI-Generated Facial Images
**Python | PyTorch | CNNs | Computer Vision**

Investigated whether convolutional neural networks trained on localized image patches can distinguish AI-generated facial images from real photographs.

Compared multiple patch sizes with full-image classification and examined tradeoffs among predictive performance, training data requirements, computational cost, and spatial interpretability.

**[View Project](./ai-face-patch-detection/)**

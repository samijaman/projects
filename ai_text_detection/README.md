# AI-Generated Text Detection Across LLMs

An NLP research project comparing traditional machine learning and transformer-based approaches for distinguishing AI-generated text from human-written text, with a focus on how well detection methods generalize to previously unseen large language models.

**Authors:** Samia Jaman, Ellie Kogan, Isabelle Borgstedt

## Project Overview

AI-generated text detectors can achieve strong performance on data similar to their training set, but an important question is whether they can recognize text generated by different language models.

This project compares three approaches:

- Logistic Regression with Bag-of-Words
- Logistic Regression with TF-IDF
- Fine-tuned DistilBERT

The models were trained on a corpus of 1,460 human- and AI-generated essays and evaluated using accuracy, precision, recall, F1-score, calibration, and cross-LLM generalization.

In addition to classification performance, the project investigates the linguistic and stylistic features that distinguish human and AI-generated writing.

## Dataset

The base dataset contains 1,460 labeled essays from the Innovatiana corpus.

Each essay is classified as:

- `0` — Human-written
- `1` — AI-generated

Approximately 6% of the original samples are AI-generated, creating a substantial class imbalance.

Additional essays generated by previously unseen LLMs were used to evaluate whether models trained primarily on GPT-generated text could generalize across models.

## Methodology

### Logistic Regression

Two Logistic Regression classifiers were trained using different text representations:

**Bag-of-Words**

Represents documents using raw word frequencies and provides an interpretable baseline for identifying lexical differences between human and AI writing.

**TF-IDF**

Weights words based on both their frequency within a document and their frequency across the corpus, reducing the influence of commonly occurring terms.

Class weighting was used to account for the imbalance between human and AI-generated samples.

### DistilBERT

A DistilBERT transformer model was fine-tuned for binary text classification using a weighted loss function to account for class imbalance.

Training and test accuracy and loss were monitored across epochs to evaluate convergence and model performance.

## Model Evaluation

Models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrices
- Reliability curves
- Cross-LLM generalization

The Bag-of-Words and TF-IDF Logistic Regression models achieved near-perfect performance on the primary test set, but their performance decreased substantially when evaluated on text from previously unseen language models.

DistilBERT achieved **97.3% overall test accuracy**, including:

- **99.6% accuracy on human-written text**
- **95.0% accuracy on AI-generated text**

## Cross-LLM Generalization

A central goal of the project was determining whether a detector trained primarily on one source of AI-generated text could recognize writing produced by other LLMs.

On the small unseen-LLM evaluation set:

| Model | Accuracy |
| --- | ---: |
| Bag-of-Words Logistic Regression | 25% |
| TF-IDF Logistic Regression | 75% |
| DistilBERT | 100% |

DistilBERT correctly classified all four unseen AI-generated essays, while the simpler lexical models showed substantially weaker generalization.

Because this evaluation contained only four unseen-LLM samples, these results should not be interpreted as evidence that DistilBERT will achieve 100% accuracy on AI-generated text from arbitrary LLMs.

## Feature Analysis

The project also investigated which linguistic characteristics influenced classification.

### Logistic Regression

Model coefficients were analyzed to identify the words most strongly associated with human and AI-generated text.

Human writing was more strongly associated with personal references, pronouns, everyday vocabulary, and conversational language.

AI-generated writing showed stronger associations with broader, more formal, and abstract vocabulary.

### DistilBERT

Gradient-based token attribution was used to identify tokens that most influenced DistilBERT's predictions.

This provided an interpretable view of the linguistic signals used by the transformer model.

## Stylometric Analysis

The project compared human and AI-generated essays using features including:

- Sentence length
- Sentence complexity
- Vocabulary richness
- Rare-word usage
- Readability
- Punctuation patterns

AI-generated essays generally exhibited greater syntactic complexity, richer vocabulary, greater rare-word usage, and lower readability.

Human-written essays showed more conversational and variable writing patterns.

## Key Takeaways

The results highlight an important distinction between test-set performance and real-world generalization.

Traditional lexical models performed extremely well on data resembling their training distribution but struggled when exposed to text from different LLMs.

DistilBERT showed stronger cross-model performance, suggesting that contextual transformer representations may capture more generalizable linguistic patterns than simple word-frequency methods.

However, the small cross-LLM evaluation set prevents strong conclusions about generalization.

## Limitations

Several limitations are important when interpreting the results:

- Only about 6% of the primary dataset is AI-generated.
- Most training examples come from a limited set of AI sources.
- Cross-LLM testing used only four additional essays.
- High test accuracy may partly reflect model-specific patterns rather than universal characteristics of AI-generated writing.
- Binary human-vs-AI classification does not capture human-AI collaborative writing.
- False positives are particularly important because incorrectly labeling human writing as AI-generated can have serious consequences.
